# OAuth for Remote MCP Servers

A vendor-neutral explainer of how LLM assistants authenticate to a remote MCP (Model Context Protocol) server over OAuth 2.1 — covering Claude Code, Claude Desktop, Cursor, and Gemini Enterprise, and the difference between public (cloud) and private (VPN) clients.

The live page is published via GitHub Pages at <https://wambamboozle.github.io/oauth-for-remote-mcp-servers/>.
